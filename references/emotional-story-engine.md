# 成人情感故事引擎

仅用于成人情感、关系驱动型项目，不得加载到少儿 Profile，也不把恋爱机制强加给其他成人题材。

## 情绪事件链

```text
关系入口状态 → 刺痛点/欲望 → 角色行动
→ 对方误读或抵抗 → 关系压力升级 → 真实信息暴露
→ 角色选择 → 情绪兑现 → 新的关系状态
```

章纲不能只写“两人争吵、加深感情”。必须明确：双方争吵前分别相信什么；哪条信息或哪个动作改变判断；谁因此改变行为；关系入口与出口在信任、距离、依赖、控制权、承诺、公开程度或身份上有何差异。

外部危险、家庭事件、事业冲突或公开场合应改变内部关系。若事件结束后双方判断、行动和关系位置均未变化，应压缩、合并或重设事件功能。

## 情绪强度

用压力、缓冲、新压力、升级、高潮、余波形成波形。缓冲可来自日常、笑点、沉默、动作照顾或短暂合作，但应积累新信息或反差；避免“吵架 → 更大声吵架”的单一升级。

## 高潮与余波

高潮必须包含人物选择与代价。其后至少安排一个可观察的验证：以前不能说、不能做、不能进入、不能公开或不能共同承担的事，现在发生了；若关系没有新的生活状态，告白或和解仍未完成兑现。

具体亲密动作、控制行为、隐藏孩子或误会桥段都不是必选模板。机制是关系失衡、压力、选择和后果。
