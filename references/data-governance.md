# 数据治理与唯一真相源

- `project_profile.md`：受众、年龄、产品形态真相源。
- `source_worldview.md`：用户原始设定证据，不混入模型补充。
- `story_bible.md`：已批准世界正典。
- `book_rules.md`：本书专属创作宪法。
- `planning/book_outline.md`：已批准宏观未来计划。
- `planning/chapter_outline/`：已批准逐章未来计划。
- `runtime/current_state.md`：已经发生的当前状态。
- `runtime/pending_hooks.md`：伏笔生命周期。
- `runtime/character_matrix.md`：身份、关系、知识边界。
- `runtime/chapter_summaries.md`：已批准历史事件。
- `runtime/batch_working_state.md`：未批准批次临时派生状态。
- `runtime/checkpoints/`：只读回滚档案。

派生文件不能反向覆盖真相源。用户明确的新指令优先，但影响已批准历史时走变更协议。
