# 同人 / 衍生创作角色一致性

仅在同人、衍生创作或已有 IP 二创项目中加载。

## Canon Anchor

在 Story Bible 或项目规则中记录每个主要原作角色的：核心性格、基础关系、行为习惯、表达方式、重要能力、核心价值观和原作明确事实，并区分资料来源、确定事实与项目私设。

## 可延伸空间

私设、平行世界、现代 AU、新关系阶段和原作空白区可以扩展，但要说明哪些锚点保留、哪些前提改变，以及改变如何导致新的行为。AU 改变处境不等于自动抹除人格逻辑。

## 高 OOC 风险

- 核心性格或价值观无过渡反转；
- 表达方式完全改变且无处境依据；
- 为推进剧情强行降智或遗忘已有能力；
- 为制造甜、爽、虐而突然失去人物逻辑；
- 把读者对原作的既有认知当成正文中所有人物都知道的信息。

审计关键选择时使用“原角色锚点 + 当前新增经历 + 可获得信息 + 关系阶段 → 行为”的因果链。偏离锚点可以成立，但必须由故事中的变化和代价支撑。
