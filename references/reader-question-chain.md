# 读者问题链

读者问题不同于人物知识边界和伏笔台账。它记录“读者此刻最想知道什么”，作为大纲、章纲和审计字段使用，不新增 Runtime 真相源。

## 基本链路

```text
Q1 当前高价值问题
→ A1 完整或部分答案
→ Q2 更具体、更严重或代价更高的问题
→ A2 新答案
→ Q3 更深层问题
```

高价值问题应来自正在发生的目标、危险、关系、秘密、规则或选择，并能影响读者对后续行动的期待。仅有“世界还有秘密”而无当前行动压力，不足以支撑章节留存。

## 规划字段

- 全书/分卷：长期主问题、阶段答案、中期再立题、终局答案。
- 章节：承接问题、本章读者问题、本章给出的答案、新问题、下一步行动压力。
- 场景：仅在需要时记录局部问题；不要为每个小段制造机械悬念。

## 审计

- 答案是否由前文证据和人物行动获得；
- 部分答案是否真正缩小未知范围，而非换句话重复问题；
- 新问题是否由答案或结果自然产生；
- 是否连续多章发生很多事件，却没有清晰读者期待；
- 是否连续开新问题而不兑现旧问题。
