# 章纲审计（3.6.1）

除原有规划一致性、因果、信息边界、伏笔、重复、高潮、体量和 Profile 检查外，增加：

- 事件链审核：每章使用“承接状态 → 人物行动/选择 → 结果 → 新压力/新状态”写清客观施工链。
- 章节价值变化：起始状态与收尾状态必须有可追踪差异，至少改变目标、知识、关系、资源、规则、位置、能力、代价、风险或承诺之一。
- 场景有效性：每个场景具备目标、阻力、转折和出口状态；换场带来新信息、新限制、新选择或新后果。
- 人物行动逻辑：事件由人物欲望、已知信息和当时能力解释，不能由作者安排或无铺垫情绪推动。
- 推进变量检查：相邻章节不可只更换危险场面；至少一个推进变量发生实质变化，并在章末留下明确行动压力。
- 高潮与不可逆变化：本章高潮应来自有代价选择，并明确其不可逆后果及后续影响。
