# 成人网文吸引力路由

仅在 `受众 = adult` 且产品属于网文型内容时加载。它补充结构审计，不替代因果、Profile、有声化或用户批准的项目规则，也不得加载到少儿 Profile。

## 按需加载

- 所有成人网文：`adult-webfiction-opening.md`、`story-promise-and-payoff.md`、`reader-question-chain.md`、`character-appeal-and-contrast.md`。
- 成人情感、关系驱动、甜宠、虐转甜、破镜重圆等：再加载 `emotional-story-engine.md`。
- 同人、衍生、已有 IP 二创：再加载 `derivative-fiction-character-consistency.md`。

## 核心目标

在“故事成立”之外持续回答：读者为什么点进来、此刻最想知道什么、本段兑现了什么、兑现后为什么还想继续。

检查以下闭环：

```text
当前问题 → 人物必须行动 → 部分答案或回报
→ 更具体的新问题/新欲望 → 压力升级 → 阶段兑现
```

外部事件必须推动至少一种内部状态：信任、依赖、距离、控制权、认知、承诺、公开程度、关系身份或情绪债。删除重大外部事件后人物关系与主线状态几乎不变，说明事件可能只有热闹而没有推进。

相邻场景除功能不同外，情绪强度也应变化。成人情感场景可使用“压力 → 短暂缓冲 → 新压力 → 升级 → 高潮 → 余波”，避免连续场景只有同强度争吵；缓冲要为新信息、新选择或新升级服务，不能让主线彻底泄气。

夸张标题、短篇高密度节奏和极端关系动作只能是特定项目可选策略，不得变成所有成人网文的硬标准。
