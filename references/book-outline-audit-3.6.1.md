# 全书大纲审计（3.6.1）

在原有世界观、角色弧、主线、支线、伏笔、体量和 Profile 审计之外，增加故事结构审核层：

- 核心故事成立性：核心命题、主角欲望、主要阻力和终局回答是否形成可持续因果链，主角选择是否决定关键结果。
- 主角故事弧：初始欲望/缺陷或错误信念、阶段性选择、代价、能力与认知变化，以及终局选择如何完成或反转故事弧。
- 分卷事件链与价值变化：每卷/大型剧情单元是否改变目标、知识、规则认知、队伍关系、资源、能力、位置、代价、风险或承诺；只换场景而不改变价值视为重复。
- 因果合理性与事件必要性：重大事件是否有触发、行动、结果和下一压力；删除该事件后，后续事实或选择是否仍能成立。
- 场景转折与高潮结构：关键场景是否有入口/出口状态；高潮是否由铺垫充分、带明确代价的角色选择解决核心困境，而非巧合、外援或突然新增能力。
- 不可逆变化：重大损失、暴露、关系破裂、规则公开和承诺等变化是否被记录并约束后续规划。
