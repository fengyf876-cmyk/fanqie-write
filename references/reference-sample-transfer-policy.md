# 参考样本迁移与防污染策略

人工样稿只提供方法证据，不自动成为 Skill 全局规则。分析样本前先建立适用范围卡：

- 受众：成人 / 少儿 / 自定义；
- 产品形态：长篇网文、短篇网络故事、分集故事、绘本有声化、同人/衍生等；
- 题材与子类型；
- 篇幅与叙事模式；
- 证据强度：单一样本 / 多个独立优秀样本 / 跨项目稳定成立；
- 可迁移范围：本项目、同类项目、跨题材、跨受众；
- 依赖项：是否依赖既有 IP 认知、具体平台、特殊标题或具体桥段。

## 规则升级等级

1. 单一样本方法只记为“候选方法”，写入项目级规则或分析记录，不升级为 Skill 硬规则。
2. 多个独立优秀样本重复出现的方法，可进入对应 Audience、产品或 Genre reference，作为推荐策略。
3. 只有跨题材、跨作品、跨项目稳定成立，并且不依赖年龄或产品前提的方法，才可进入通用结构层或审计硬项。

## Audience 隔离硬门

- Audience-specific 方法不得跨 Audience 自动迁移。
- 成人样本不得修改、覆盖或限制 `children_8_12` Profile；少儿样本不得反向限制成人 Profile。
- 只有因果、人物行动逻辑、状态变化、承诺兑现等被明确证明跨受众成立的结构原则，才可进入通用层。
- 每次采用样本方法时，记录它属于通用层、成人网文层还是题材/子类型层；无法判定时留在项目级候选层。

## 学机制，不学表皮

不得把样本中的人物、CP、专有设定、台词、谜题、独特反转或桥段组合复制进新项目。隐藏孩子、假恋爱、醉酒、发烧、误伤、突然同居等重复表皮不构成通用方法；只提炼其背后的关系失衡、压力、选择、后果、承诺或情绪兑现机制。

短篇高密度节奏不得直接套入长篇。长篇需要小兑现、中兑现、阶段兑现、再立题和最终兑现；同人可借用读者已有认知，原创项目必须自行完成人物、能力和关系前提的首次建模。
