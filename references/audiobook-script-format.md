# 有声书成品话本格式

## 基本语法

- 普通旁白直接成段，不加 `【旁白】`。
- 角色台词：`【角色名】台词`。
- 表演提示：`【角色名 情绪或状态】台词`，只保留演员可执行信息。
- 内心：`【角色名 内心】内容`。
- 多人同声：`【角色A、角色B】内容`。
- 通用声效：`【声效】具体声音`。
- 角色标签后不加冒号；纯动作不要塞进角色标签。
- 若项目启用特定参考话本 profile，以该 profile 的已批准语法覆盖通用声效格式。

## 听觉来源辨识

有声书不能依靠颜色、缩进、用户名位置、聊天框、屏幕画面来区分来源。现实人物、系统、直播/弹幕、远端通讯、内心、回忆或梦境切换时，至少使用一种可听提示：
- 旁白过桥，例如“直播间里，弹幕瞬间刷屏”；
- 固定系统播报标签或专属声效；
- 稳定角色标签或音色设定；
- 明确转场声效。

首次建立一种声源时提示要充分，规则稳定后可简化。关键情报必须由可听文本成立，声效只能增强，不能替代信息。

## 声效密度

声效优先用于场景建立、动作关键点、转场、危险触发和空间变化。不要为每个微动作标声效。

## 审计

检查角色标签稳定、来源可辨、旁白不过度解释、台词不连续超长、没有只有“看页面”才能理解的内容。
