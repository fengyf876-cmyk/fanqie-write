# 审计体系索引（3.4.1）

3.4.1 在三阶段审计之前新增 Project Profile 门。所有审计必须先知道“写给谁听、做成什么产品”。

## 0. Profile 审计

见：
- `project-profile-routing.md`
- `audience-children-8-12.md`
- `audience-adult.md`

检查受众、年龄、Audio Product、Genre 与项目规则是否匹配。

## 1. 全书大纲审计

见 `book-outline-audit.md`。

覆盖世界观、角色弧、主线、支线、反派、伏笔、体量和 Profile 适配。

## 2. 全书章纲审计

见 `chapter-outline-audit.md`。

覆盖因果、时间线、信息边界、伏笔、循环、高潮、章/集预算、有声化和 Profile 单元规则。

## 3. 正文审计

见 `draft-audit.md`。

覆盖 Plan Compliance、Profile Compliance、字数/单集长度、听觉可理解性、有声格式、AI去味、连续性、对话/旁白和专项场景。

## 4. 严重程度

- Critical：破坏核心正典、已批准 Profile/规划或真正的平台硬红线。
- Major：显著削弱结构、人物、伏笔、听觉理解、年龄适配或产品可用性。
- Minor：局部表达、节奏、格式、清晰度问题。
- Note：可选优化。
