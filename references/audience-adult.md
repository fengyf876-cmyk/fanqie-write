# 成人有声规则

成人项目不继承少儿短集字数、开篇字数、台词比例等硬参数。章长读取批准的 `length_plan.md`。

允许更复杂的心理、氛围、关系和世界信息，但仍需满足有声可理解性：来源切换可听、关键空间关系清楚、长说明有节奏分割。

高智商人物同样需要证据链；成人叙事可以隐藏部分证据制造悬疑，但最终解答必须与已给信息兼容。重大冒险需要动机、代价和必要性。

## 成人网文条件路由

当产品属于成人网文型内容时，加载 `adult-webfiction-engagement.md`。该文件再按项目类型路由开篇吸引力、承诺兑现、读者问题链、人物魅力、情感故事引擎和同人一致性模块。

这些规则不因 `受众 = adult` 就全部启用：情感引擎仅用于成人情感/关系驱动项目，同人一致性仅用于已有 IP 衍生项目。成人样本提炼的方法不得写入或覆盖少儿 Profile。
